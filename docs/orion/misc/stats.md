# Statystyki na żwie

Orion jest praglądarką telemetryczną o zerowej liczbie użytkowników i nie znamy faktycznej liczby użytkowników z niej korzystajczych. Zatem nastąpńń najlepszć liczbć, jakć możemy śledzić, jest liczba użytkowników [płacenie za Oriona](https://kagi.com/onboarding?p=orion_plan).

Mama bardzo prostć wizualizację liczby czonków Orion+ pod adresem [kagi.com/stats](https://kagi.com/stats?sub_stats=orion).
