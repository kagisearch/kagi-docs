# Widgets

## Answer Box

The answer box widget provides quick results for math computations, science queries, and general facts. It's powered by Wolfram|Alpha.

#### Example Queries
- [`1+23`](https://kagi.com/search?q=1%2B23) -> `= 24`
- [`integral of x^2`](https://kagi.com/search?q=integral+of+x^2) -> `= x^3/3`
- [`age of obama`](https://kagi.com/search?q=age+of+obama) -> `= 64 years`
- [`electrons in carbon atom`](https://kagi.com/search?q=electrons+in+carbon+atom) -> `= 6 electrons`

## Blast from the Past

This widget sources results from the Internet Archive to show you results as they would have been back in the day.

#### Example Queries
- [`windows xp`](https://kagi.com/search?q=windows+xp#:~:text=Blast%20from%20the%20Past)

## Computer

The computer widget offers a wide variety of calculations and useful features, such as:
- Currency conversion
- Crypto conversion
- Math
- Timezone conversion
- UUID generation
- MD5 of query
- URL encode/decode of query
- Base64 encode/decode of query
- Hex/octal/decimal conversions

#### Example Queries
- [`generate uuid`](https://kagi.com/search?q=generate+uuid)
- [`45ft in m`](https://kagi.com/search?q=45ft+in+m)
- [`1usd to eur`](https://kagi.com/search?q=1usd+to+eur)
- [`123 in hex`](https://kagi.com/search?q=123+in+hex)

## Clock

The clock widget provides time results, such as current time in your locale or a specific timezone. Conversion queries can also be given to show the time in another location based on a given time and location.

#### Example Queries
- [`current time`](https://kagi.com/search?q=current+time)
- [`time in amsterdam`](https://kagi.com/search?q=time+in+amsterdam)
- [`10pm boston in amsterdam`](https://kagi.com/search?q=10pm+boston+in+amsterdam)
- [`9am sf in chicago`](https://kagi.com/search?q=9am+sf+in+chicago)

## Inline Maps

This widget provides quick access to map results without having to leave the main results page.

#### Example Queries
- [`coffee near me`](https://kagi.com/search?q=coffee+near+me)
- [`sushi near seattle`](https://kagi.com/search?q=sushi+near+seattle)

You can also search for local restaurant names, for example [`veggie galaxy`](https://kagi.com/search?q=veggie+galaxy) if you're in Boston.

## Shipping Widget

When searching with a shipping tracking number, a widget can be shown that has
information about the package and its current status.
Kagi currently supports these providers when provided a shipping tracking number:

| Provider | Link to track | Inline tracking info |
|----------|:-------------:|:--------------------:|
| USPS     |             x |                    x |
| UPS      |             x |                    x |
| FedEx    |             x |                    x |
| Australia Post |       x |                    x |
| Canada Post |          x |                    x |
| Austrian Post |        x |                      |
| Haypost  |             x |                      |
| Israel Post |          x |                      |
| Korea Post |           x |                      |
| Post Aruba |           x |                      |
| Post Nord |            x |                      |
| Royal Mail |           x |                      |

If there are any shipping providers missing from this list that you'd like to see, please create an issue on [kagifeedback.org](https://kagifeedback.org).

#### Example Queries
- 9400108205497180032214 (USPS, Processing)
- 9449008205499676477068 (USPS, Delivered)

## Stopwatch/Timer

This widget displays a basic stopwatch/time combo. The stopwatch is capable of splits, and the timer can play sound when it ends. These widgets do not work when JS is disabled.

#### Example Queries
- [`stopwatch`](https://kagi.com/search?q=stopwatch)
- [`timer`](https://kagi.com/search?q=timer)
- [`5 minute timer`](https://kagi.com/search?q=5+minute+timer)
- [`3 min timer`](https://kagi.com/search?q=3+min+timer)

## Translator

This widget displays a basic translation panel inline with the search page, powered by Kagi Translate. You can also open a full Kagi Translate session from the widget for more advanced options.

#### Example Queries
- [`translate oj! vilken överraskning to english`](https://kagi.com/search?q=translate+oj!+vilken+%C3%B6verraskning+to+english)
- [`ahora in english`](https://kagi.com/search?q=ahora+in+english)
- [`hello world in spanish`](https://kagi.com/search?q=hello+world+in+spanish)

## Videos

This widget shows relevant videos inline to the results page.

## Weather

This widget shows the current and forecasted weather for the day and week. You can specify a location or use your current location. Currently this is powered by Open-Meteo.

#### Example Queries
- [`weather london`](https://kagi.com/search?q=weather+london)
- [`weather`](https://kagi.com/search?q=weather)
- [`weather in sf`](https://kagi.com/search?q=weather+in+sf)

## What's my IP?

This widget displays your current IP address and geoIP information. This is not stored and uses an offline lookup table to display data.

#### Example Queries
- [`my ip`](https://kagi.com/search?q=my+ip)
- [`whats my ip address`](https://kagi.com/search?q=whats+my+ip+address)

## Wikipedia

This is the most common widget to see, it will show up with a small summary and infobox whenever a related Wikipedia article is found for your query.

#### Example Queries
- [`chicago`](https://kagi.com/search?q=chicago)
- [`steve wozniak`](https://kagi.com/search?q=steve+wozniak)
